# Ficha do Pré-Conselho — IFPI Campus Angical

Versão digital da ficha de Pré-Conselho do IFPI Campus Angical do Piauí.
Em papel, a ficha serve para levantar, antes do conselho de classe, as
dificuldades e demandas de cada turma. Este projeto leva esse
preenchimento para um formulário web, pensado para uso em celular e computador.

Projeto em desenvolvimento, feito como atividade extracurricular para
praticar HTML, JavaScript e Git.

## Tecnologias

Em uso:
- HTML
- Tailwind CSS v4 (via CDN)

Planejado:
- JavaScript (comportamento do formulário)

## Como abrir

1. Clonar o repositório.
2. Abrir a pasta no editor e iniciar com a extensão Live Server,
   ou abrir o `index.html` direto no navegador.

É necessário ter internet: o Tailwind é carregado por CDN e, sem conexão,
a página aparece sem estilo.
